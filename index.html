🤖 J.A.R.V.I.S.

Just A Rather Very Intelligent System — Sistema de Ayuda

🚀 Comenzar la instalación

Bienvenido al sistema de ayuda de J.A.R.V.I.S., su asistente de escritorio con inteligencia artificial para Windows 10/11. Funciona con modelos de IA tanto locales (Ollama) como en la nube (GitHub Models con GPT-4o-mini, Google Gemini), y es capaz de realizar tareas complejas de forma autónoma: lee la pantalla, planifica pasos y ejecuta acciones sin intervención del usuario.

⚡ Inicio rápido

1

Instale los requisitos

Python 3.11+, Ollama y Git.

2

Clone e instale

git clone https://github.com/Pausiar/JARVIS.git
cd JARVIS
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
3

Descargue el modelo de IA

ollama serve          # en una terminal
ollama pull mistral   # en otra (~4.4 GB)

O use modo cloud para evitar descargas.

4

Ejecute JARVIS

python main.py

Se abrirá la ventana HUD. ¡Listo! → Ver la interfaz

🧩 ¿Qué puede hacer J.A.R.V.I.S.?

🧠
IA dual: Local + Cloud
Usa Ollama (local) o APIs cloud gratuitas: GitHub Models (GPT-4o-mini, 20K req/día) y Google Gemini (Gemini 2.0 Flash). Sin coste.
👁️
Visión OCR
Lee la pantalla, hace clic en texto, interactúa con cualquier app.
⚙️
Control del sistema
Apps, volumen, brillo, ventanas, portapapeles, capturas de pantalla.
📄
Documentos
Lee PDF, Word, Excel. Resuelve ejercicios y escribe las soluciones.
🎙️
Voz natural
Entrada de voz (Whisper) y síntesis TTS (Piper) en español.
⏰
Automatización
Recordatorios, timers, rutinas programadas, aprendizaje de procedimientos.
🤖
Agente autónomo
Va más allá de comandos simples: planifica, ejecuta y verifica tareas complejas de varios pasos de forma independiente.
📝
Resuelve ejercicios
Lee un PDF con ejercicios, los resuelve con la IA y escribe las soluciones en Word, Google Docs u otra app.
📌 Temas populares
  • Catálogo completo de comandos
  • Cómo funciona la visión OCR
  • Resolver ejercicios de un PDF
  • Configurar modo cloud (sin GPU)
  • Resolver problemas comunes
